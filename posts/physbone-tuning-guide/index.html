PhysBone 调参入门：头发裙摆不再炸毛

Pull、Spring、Gravity 到底谁管什么？一篇讲清 PhysBone 核心参数，附头发、裙摆、尾巴的常用参考值。

VRChat PhysBone 物理 入门 新手系列

模型头发硬得像钢盔、裙摆抖成帕金森、尾巴飘成铁棍 —— 九成是 PhysBone 参数没调对。这篇带你建立参数直觉。

PhysBone 是什么

PhysBone 是 VRChat 官方的骨骼物理组件，让头发、裙摆、尾巴、饰品这些部位随动作自然摆动。它挂在骨骼链的根骨骼上，链上所有子骨骼一起被驱动。

选中组件后，Force 区的参数按 Integration Type 分两套，先确认你看的是哪套：

  • Simplified：Pull、Spring、Gravity、Gravity Falloff、Immobile Type —— 大多数情况用这套就够了；
  • Advanced：用 Momentum 和 Stiffness 替代 Spring，对外力更灵敏，做精密效果才需要。

核心参数直觉

参数 管什么 调大了会怎样
Pull 骨骼「想回到初始姿势」的劲 太大 → 硬邦邦，像铁丝
Spring 摆动的惯性/跟随速度 太大 → 抖成帕金森
Gravity 静止时的下垂方向 正值下拉，负值上拉
Gravity Falloff 重力对越靠末端的骨骼作用越弱 1.0 = 完全不受重力
Immobile 抵抗身体移动带来的甩动 太大 → 跑起来纹丝不动

重点说 Gravity Falloff，这是最容易被忽略的神器：

  • 建模时头发已经是自然垂落的理想姿势 → 设 1.0，静止时完全保持建模姿势；
  • 头发是 45° 翘起来的、想要自然弯下来的弧度 → 设 0.5~0.8，只让一部分重力生效。

三个经典场景

头发炸毛 / 翘起来

  1. Gravity Falloff 调到 1.0 试试（很多模型炸毛就是重力不该参与）；
  2. 还有问题就把 Limit Type 设为 Limit Angle，限制每根骨骼的最大偏转角，比如 45°；
  3. 弹跳太夸张就降 Spring、加 Pull。

裙摆穿模

物理不会让裙子避让大腿，需要 Collider（碰撞体）：

  1. 在身体（大腿、胯）上添加 VRC PhysBone Collider，调好形状和半径；
  2. 把它们加进裙摆 PhysBone 的 Colliders 列表；
  3. 同时给裙子设 Limit Rotation，大幅动作时也不会翻进去。

尾巴太飘 / 太僵

  • 太飘（惯性大）：降 Spring；
  • 太僵（没惯性）：升 Spring、降 Pull；
  • 想要尖端更灵活：把 Distribution（多级骨骼的分配曲线）往末端倾斜。

性能红线

PhysBone 是有计算成本的，尤其 Quest 平台：

  • Quest 端 8 个 PhysBone 组件就到 Poor 线了，合并骨骼链、删掉可有可无的链条是常规操作；
  • PC 端组件数量宽松，但每个组件的 Max Chain Length（作用骨骼级数）越长越贵，够用就好。

提示：调参时开 Unity 的 Play 模式 + Av3 Emulator 实时看效果，改完把数值抄回组件再退出，比反复上传快得多。

调参没有标准答案，以上数值都是起点 —— 复制别人的数值不如理解每个参数「管什么」。祝你的模型从此发丝柔顺。
