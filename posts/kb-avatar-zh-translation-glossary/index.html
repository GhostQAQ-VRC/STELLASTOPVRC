四组高频混淆术语辨析：Texture≠Material、State≠Animation、Avatar≠头像、Animator≠动画师（含教学话术）

结论：四组术语最容易被中文社区误译混用，判别要点与教学话术如下（来源：VRCD 关键词对照表 §3，community-tested）。

① Texture vs Material：Texture = 贴图/纹理（图片本身）；Material = 材质球（包含 Texture + Shader + 渲染属性）。常见错误是把 Texture 译成「材质」，应译为「贴图/纹理」。教学话术：「Material 是盒子，Texture 是装在盒子里的画」。

② State vs Animation：State = 状态（Animator 中的方块）；Animation = 动画（状态内播放的内容）。常见错误是把 State 译成「动画」，应译为「状态」。教学话术：「State 是播放器的按钮，Animation 是按钮播放的歌曲」。

③ Avatar ≠ 头像：Avatar = 虚拟形象（VRChat 中的 3D 角色）；「头像」通常指 2D 图像（如社交媒体头像）。官方文档中 Avatar 专指 3D 虚拟形象。教学话术：「Avatar 是 3D 角色，不等于 2D 头像」。

④ Animator ≠ 动画师：Animator = 动画器/状态机（Unity 组件）；「动画师」是职业称谓。常见错误是把 Animator 译成「动画师」，应译为「动画器/状态机」。教学话术：「Animator 是 Unity 里的组件，不是做动画的人」。

VRChat 术语翻译规范建议：首次出现中英并标、避开欠标准译名、SDK/API/代码场景避免中文译名、教学按入门进阶专业分层

结论：中文社区文档写作的术语规范分三类——推荐做法、避免做法、教学场景分层（来源：VRCD 关键词对照表 §4，community-tested）。

推荐做法：术语首次出现时同时标注英文和中文，写法如「Animator（动画器）」；后续可仅用中文，但保留英文别名；跨文档引用时使用统一译名；复杂术语优先直接用英文原文，避免翻译歧义。

避免做法：不使用对照表中标 ⚠️ 的欠标准译名；不自创译名（除非已在社区广泛流通）；在 SDK、API、代码相关的场景避免使用中文译名。

教学场景分层：入门教学多用中文译名，降低理解门槛；进阶教程中英双语并行，帮助建立工程对应关系；专业文档优先用英文，保持准确性。
