VRChat Trust Rank — 玩家信任等级系统（层级权限、升降级机制与创作者上传前提）

知识库 avatar

VRChat Trust 与 Safety 双组件架构：Trust System 决定上传资格，Safety System 决定 Avatar 特性处理方式

结论：VRChat 的信任机制由 Trust System（信任系统）与 Safety System（安全系统）两个组件构成，二者相互独立但联动（来源：docs.vrchat.com/docs/vrchat-safety-and-trust-system，official）。

分工：Trust System 决定一个用户是否被允许上传内容；Safety System 让每个用户自行决定如何处理其他用户 Avatar 的特性（例如屏蔽特效与声音）。整套系统的设计目标是保护用户免受滋扰行为影响，典型滋扰手段包括屏幕空间 Shader、响亮声音、麦克风滥用、视觉噪声以及恶意粒子。

关键联动规则：即使某个用户把 Safety 等级设为 None（即不主动屏蔽任何人），被系统标记为 Nuisance（滋扰用户）的玩家，其 Avatar 仍会被隐藏——Nuisance 的屏蔽不完全取决于个人 Safety 设置。

VRChat 七个 Trust Rank 权限对照表：New User 是上传权限节点，Friends 为特殊等级

结论：用户 Trust 决定 Trust Rank，是在 VRChat 中度过的时间、贡献的内容、结交的朋友等多个变量的综合指标；共 7 个等级外加特殊的 Friends 类别，其中 New User 是获得上传权限的关键节点（来源：docs.vrchat.com/docs/vrchat-safety-and-trust-system，official）。

Rank 名称 关键权限 备注
Visitor 访客 无法上传 全新账号
New User 新用户 可上传 Avatar/World 由 Visitor 升级而来的关键节点
User 普通用户 标准 高等级隐藏 Trust 标志后显示为此等级
Known User 已知用户 可选择隐藏 Trust 标志
Trusted User 信任用户 可选择隐藏 Trust 标志
Nuisance 滋扰用户 大多数 Avatar 被屏蔽 因被举报而标记
VRChat Team VRChat 团队 不可伪装 内部账号

Friends（好友）特殊规则：Friends 是一种特殊的 Trust Rank，在 Normal Shield Level 下好友的所有 Avatar 特性都开放显示；Friends 不显示在 Nameplate 上，可通过 Nameplate 上的 Trust 标志区分。玩家还可以像配置其他 Trust Rank 一样自定义 Friends 的 Safety 设置，而不是只能接受 Normal 默认行为。

Visitor 升级 New User 即获得上传权限：游玩行为自动累积 Trust 并触发系统通知

结论：新账号从 Visitor 升级为 New User 后即可上传内容；升级由正常游玩行为自动触发并伴随系统通知，无需手动申请（来源：docs.vrchat.com/docs/vrchat-safety-and-trust-system，official）。

机制细节：

  • 升级前提：必须使用 VRChat 账号；Steam、Oculus、Viveport 等平台账号不适用此升级路径，也无法直接获得上传权限，需先转换为 VRChat 账号。
  • 升级方式：探索世界、添加好友、创建内容都是有效行为，正常游玩即可累积 Trust。
  • 触发条件：Trust 达到阈值时自动升级。
  • 升级反馈：用户会收到 Trust Rank 转换的通知，并被引导至 VRChat 官方文档开始创建内容。

三类行为不会增加 VRChat Trust：AFK 挂机、批量低质量内容、大量加好友

结论：在世界中挂机（AFK）、批量上传低质量内容、大量添加好友这三类行为都不会增加 VRChat Trust——单纯的数量不能替代质量（来源：docs.vrchat.com/docs/vrchat-safety-and-trust-system，official，页版本 1.0 本地化 2026-06-30）。

官方明确列出的无效行为：

  1. 在世界中挂机或闲置（AFK）——单纯挂着不算有效游玩。
  2. 上传大量低质量内容——上传数量本身不是信任信号。
  3. 大量添加好友——好友数量不是信任信号。

对照的有效提升方式：正常游玩、添加真实好友并创建高质量内容。

Known User 及以上可隐藏 Trust 标志：对外显示降为 User 且 Safety 系统按 User 档处理

结论：VRChat 中 Known User 及以上等级（含 Trusted User）可以选择关闭 Trust 标志显示；关闭后对外显示为 User，并且其他人的 Safety 系统也按 User 等级而非实际等级来处理其 Avatar 特性（来源：docs.vrchat.com/docs/vrchat-safety-and-trust-system，official）。

规则细节：

  • 适用范围：Known User、Trusted User 等 Known 以上的等级都可操作。
  • 显示效果：关闭后名字旁显示为 User。
  • 安全联动：Safety 系统对该用户的默认屏蔽策略按 User 档执行——实际高等级带来的宽松 Safety 待遇同时失效。
  • 默认状态：Known 和 Trusted 用户默认显示 Trust 标志，需手动切换才会隐藏。

设计目的：给不希望公开展示高 Trust 等级的用户提供隐私选项。

Nuisance 滋扰用户：Quick Menu 指示符识别，Avatar 大多数情况被完全屏蔽

结论：Nuisance（滋扰用户）是被举报标记出的特殊 Trust Rank；打开 Quick Menu 查看该用户时，其 Nameplate 顶部会出现 Nuisance 指示符，且大多数情况下这些用户的 Avatar 会被完全屏蔽（来源：docs.vrchat.com/docs/vrchat-safety-and-trust-system，official）。

实际后果：

  • 对普通用户：大多数情况下看不到 Nuisance 用户的模型与特效。
  • 对世界创作者：Nuisance 用户的 Avatar 几乎不会对 World 的流量（性能负担）产生贡献，因为其 Avatar 已被屏蔽。

结论：使用 Steam/Oculus/Viveport 平台账号登录 VRChat 时无法直接上传内容，必须转换绑定到一个全新的、空白的 VRChat 账号；转换完成后原平台账号信息不会转移，且过程不可逆（证据层级 inferred：源自 user-guide/setup-2fa.md 与平台通用知识，经 entities/avatar/trust-rank.md §2.2 归档，未经官方 Trust 主文档直接印证）。

  1. 在 VRChat 客户端内打开 Settings。

VRChat 2FA 仅限 VRChat 账号启用：官网 Edit Profile 内设置，推荐 Authy 验证器

结论：VRChat 的两步验证（2FA）只面向使用 VRChat 账号登录的用户，Steam、Oculus、Viveport 平台账号无法启用；设置入口在 VRChat 官网个人资料页（来源：docs.vrchat.com/docs/setup-2fa，official，经 entities/avatar/trust-rank.md §2.3 转述）。

设置步骤：

  1. 登录 VRChat 网站。
  2. 进入 Edit Profile（编辑资料）。
  3. 选择 Two-Factor Authentication（两步验证）。
  4. 启用并绑定验证器应用，推荐 Authy（支持云备份，换机不易丢失）。

VRChat Trust 快速升级四步路径：积极游玩、真实社交、高质量创作、避免 AFK

结论：快速提升 VRChat Trust 的官方推荐路径是积极游玩、添加真实好友、创建高质量内容并避免挂机（来源：docs.vrchat.com/docs/vrchat-safety-and-trust-system，official）。

四步路径：

  1. 新用户阶段积极游玩 VRChat，通常几天内即可升到 New User。
  2. 添加真实好友，而不是批量加陌生人——大量加好友不会增加 Trust。
  3. 获得上传权限后，创建高质量的 Avatar 和 World，内容质量是后续升级的核心。
  4. 避免 AFK 挂机，挂机时间不计入 Trust。
