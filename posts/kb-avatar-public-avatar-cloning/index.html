Avatar Cloning 定义与两个前提条件：复制他人 Public Avatar 到自己列表

Avatar Cloning（公共 Avatar 克隆）是 VRChat 的玩家侧 UX 功能：玩家可以把其他玩家正在穿的 Public Avatar 复制到自己的 Avatar 列表中[FACT]。该功能属于玩家侧 UX 文档范畴，不涉及创作者的核心创作流程。

前提条件有两个且缺一不可：

  • 对方 Avatar 必须标记为 Public；
  • 对方必须启用 Allow Avatar Cloning[FACT]。

边界说明：官方文档未说明克隆是否有数量限制或频率限制，此点为未知项。

克隆流程：Quick Menu 点击玩家选 Clone Avatar 后自动切换并永久保留

克隆 Avatar 的标准流程共六步：

1. 看到某玩家穿的 Avatar（你感兴趣）
2. 打开 Quick Menu（Desktop 按 ESC；VR 按 Menu 按钮）
3. 点击该玩家
4. 满足前提条件时显示 "Clone Avatar" 按钮
5. 点击 "Clone Avatar"
6. 自动切换到该 Avatar

前提条件：对方 Avatar 为 Public 且对方启用 Allow Avatar Cloning[FACT]。

结果与留存：点击后玩家自动切换到该 Avatar；克隆是一次性的永久保留——克隆来的 Avatar 会留在玩家的 Avatar 列表中[FACT]。

禁用 Allow Avatar Cloning 防当前 Avatar 被克隆：Public 状态不变 + Auto Disable 离开世界自动禁用

防止被克隆的第一种方法是在 VRChat Settings → Avatar 设置中禁用 Allow Avatar Cloning：它能防止当前 Avatar 被其他人克隆，即使该 Avatar 是 Public 也有效[FACT]。此方法不改动 Avatar 的 Public 状态，适合临时不让克隆的场景。

配套选项 Auto Disable Avatar Cloning：启用后，离开世界时会自动禁用 Allow Avatar Cloning，从而防止忘记手动禁用导致持续暴露[FACT]。注意它默认关闭，需要用户主动启用。

例外与边界：

  • 该开关只作用于当前 Avatar，切换 Avatar 后需重新设置；
  • 需要用户手动管理开关状态。

原理：克隆按钮仅在前提条件满足时显示，禁用克隆开关后克隆入口即失效。

设为 Private 彻底防克隆：vrchat.com/home/avatars → Make Private，仅对自己上传的 Avatar 有效

彻底防止克隆的方法是把自己上传的 Avatar 设为 Private。路径：VRChat 网站 vrchat.com/home/avatars → My Avatars → Make Private。效果是 Avatar 从 Public 列表移除，没有人能克隆[FACT]。

关键限制：只对自己上传的 Avatar 有效，别人的 Avatar 你不能设为 Private[FACT]。从他人处获得的 Avatar 无法用此方法保护。

原理：Private Avatar 不在可克隆的 Public 列表内，因此从源头消除克隆入口。

防克隆决策矩阵四场景对照：保持可克隆 / 设 Private / 临时禁用 / Auto Disable

官方决策矩阵按四种场景给出推荐做法：

情况 建议
想让别人克隆你的 Avatar 保持 Public + 启用 Allow Avatar Cloning
仅自己使用 设 Private
临时不让克隆 禁用 Allow Avatar Cloning（不取消 Public）
离开世界后自动恢复安全 启用 Auto Disable Avatar Cloning

核心原则：克隆可行性由 Avatar 的 Public 状态与 Allow Avatar Cloning 开关共同决定，按使用场景选择对应组合即可。

例外：设 Private 仅限自己上传的 Avatar[FACT]。

克隆风险等级表：立即克隆与不可选择性阻止为中风险、跨会话保留与 Auto Disable 默认关闭为低风险

官方文档列出四项克隆相关风险及等级：

风险项 等级 说明
Public + Allow Cloning → 自动克隆 中 别人可立即克隆
跨会话保留 低 一次克隆永久在你的 Avatar 列表
不能选择性阻止 中 不能只对某些人禁用克隆
Auto Disable 需手动启用 低 默认关闭，需用户主动启用

解读：中风险的根源在于 Public + 允许克隆的组合默认对外完全开放且无法按对象区分；低风险项则属于可控的留存与配置问题，通过主动管理开关即可缓解[FACT]。

创作者须知：Public Avatar 默认可被克隆、作者无通知、防克隆两条路径

从创作者角度须知[FACT]：

  • Public Avatar 默认可被克隆，除非作者主动禁用；
  • 别人克隆你的 Avatar 时不会收到任何通知，作者无感知。

不希望 Avatar 被克隆时的两条路径：

  • 彻底方案：把 Avatar 设为 Private；
  • 临时方案：禁用 Allow Avatar Cloning。
