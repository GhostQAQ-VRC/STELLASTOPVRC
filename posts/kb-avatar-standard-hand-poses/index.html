VRChat 平台固定定义 7 种标准手姿：Gesture 数值 0=Neutral 到 7=Thumbs Up

结论：VRChat 平台固定定义了 7 种标准手姿——Fist（拳）、Open Hand（张开）、Point（指点）、Thumbs Up（点赞）、Victory（胜利）、Hand Gun（手枪）、Rock N Roll（摇滚），玩家不能自行定义或修改这套平台定义（来源：docs.vrchat.com/docs/valve-index + docs.vrchat.com/docs/touch 本地化译本，official）。

机制与触发条件：这 7 种手姿是玩家必须做出的物理手势，创作者在 Avatar Animator 中通过 Gesture Animator Parameters 监听并响应这些手势；玩家必须实际做出相应手姿，才能触发对应数值。

Gesture 数值映射（Animator 中 Gesture 参数取值）：0=Neutral、1=Fist、2=Open Hand、3=Point、4=Victory、5=Rock N Roll、6=Hand Gun、7=Thumbs Up。

Valve Index 控制器 5 指电容传感器与 7 种手姿精确定义：pinky/ring/middle/trigger/thumb 加 squeeze

结论：Valve Index 控制器包含 pinky（小指）、ring（无名指）、middle（中指）、trigger（食指，通过 trigger 按压）、thumbpad/touchpad/buttons（拇指）五类手指电容传感器，外加 squeeze sensor（握力）；因支持 5 指独立追踪，7 种标准手姿在 Index 上有精确到每指状态的完整定义（来源：docs.vrchat.com/docs/valve-index 本地化译本，official）。

两者在小指与中指两个位置上不同，官方提示以小指位置区分 Victory 与 Rock N Roll。

对 Valve Index 用户的手势提示：用 5 指传感器准确做手势；闭手时注意 pinky/ring 的弯曲——4 指全弯下时这两根手指的动作可能不明显。

Valve Index 手指持续追踪机制：开/合精度足够、做手势时 Avatar 手指立即响应无需 Gesture Toggle

结论：在 Valve Index 控制器上，手指始终追踪控制器上传感器的状态；该追踪不完全精确，但区分手指开/合状态已足够，这种持续追踪改善沉浸感（来源：docs.vrchat.com/docs/valve-index 本地化译本，official）。

对玩家的效果：Index 用户做手势时 Avatar 手指立即响应，无需 Gesture Toggle。

对创作者的价值：可以精确控制每种标准手姿对应的 Avatar 表现。

Oculus Touch 只有中指/食指/拇指 3 指明确追踪：grip/trigger/thumbstick 推断，小指无名指靠算法

结论：Oculus Touch 控制器只有 3 个明确追踪的手指——中指（通过 grip pull 推断）、食指（通过 trigger pull 推断）、拇指（通过 thumbstick/button 推断）；小指（pinky）和无名指（ring）的状态通过算法推断，不是独立追踪（来源：docs.vrchat.com/docs/touch 本地化译本，official）。

Touch 上 7 种标准手姿按 3 指定义，典型例子：Rock N Roll 为中指 Up + 食指按 trigger + 拇指 Down。

对 Oculus Touch 用户的手势提示：用 grip pull 控制中指（不像 Valve Index 那样直接）；拇指状态通过 thumbstick 推断。

Valve Index 与 Oculus Touch 手姿检测差异：Rock N Roll 与 Victory 用食指区分、Index 更精确

结论：同一手姿名称在 Valve Index 与 Oculus Touch 上的实际检测信号不同，关键差异有 4 点（来源：docs.vrchat.com/docs/valve-index + docs.vrchat.com/docs/touch 本地化译本，official）：

  1. Touch 没有独立的 pinky/ring（小指/无名指）追踪。
  2. Rock N Roll 在 Touch 上是「中指上 + 食指按」。
  3. Victory 在 Touch 上是「中指上 + 食指未按」。
  4. Index 通过小指位置区分 Rock N Roll 与 Victory。

精度对比：Index 更精确（5 指独立追踪）；Touch 通过算法推断无名指和小指。

为 Oculus Touch 用户设计 Avatar 的 3 条适配规则：不假设 5 指追踪、双控制器测试、按 Animator 参数检测

结论：为 Oculus Touch 用户设计 Avatar 时，创作者应遵守 3 条规则（来源：docs.vrchat.com/docs/touch 本地化译本，official）：

  1. 不要假设 5 指独立追踪。
  2. 测试时 Valve Index 与 Oculus Touch 两种控制器都试。
  3. 手势检测应基于 Animator Parameters（0-7 数值），而不是物理手指状态。

规则原因：Touch 没有独立的小指/无名指追踪，同一手姿的物理信号与 Index 不同；只有 Animator 中的 Gesture 数值在两种控制器上都可靠。

Valve Index 自定义绑定两条铁律：thumb-touchable 按钮须分配相同 touch 事件；Jump/Mic/Gesture Toggle/Action Menu 是 hard input

结论：Valve Index 自定义绑定有两类必须遵守的注意事项（来源：docs.vrchat.com/docs/valve-index 本地化译本，official）。

拇指判定约束：VRChat 通过检查每个 thumb 可触及按钮的 touch 事件来判断拇指是否弯曲；如果 thumb-touchable 按钮没有为相同 touch 事件分配绑定，VRChat 就无法判断拇指弯曲，导致手部追踪不正确。

不可重新分配的 hard input 清单：Jump、Mic Toggle、Gesture Toggle、Action Menu Left / Right。

实践含义：自定义绑定时不要改动这四个 hard input；凡是被拇指能碰到的按钮，都要保证相同 touch 事件的绑定一致，否则拇指弯曲判定失效。

Avatar 手部 Rigging 标准流程：Unity Mechanim + Mixamo YBot 标准、Muscles & Settings 测试、多控制器一致表现
